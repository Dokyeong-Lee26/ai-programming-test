# ai-programming-test

## 12주차 실습: 데이터 정제 · 분석 · 검증

### 1. 데이터 정제 (`scores_2026.csv`)
- 원본: 114행 5열
- 정제 기준 및 제외 내역
  - 점수 결측치(`NaN`) 6행 제거 → 108행
  - 완전 중복 행 4행 제거 → 104행
  - `반`, `과목` 문자열 앞뒤 공백(`.str.strip()`) 제거
  - 점수 범위(`0`~`100`) 밖 이상치(`-5`, `999`) 4행 제거 → **최종 100행**

### 2. 분석 결과 및 해석
- **반별 평균:** 1반 `78.24`점, 2반 `71.44`점
- **과목 × 반 평균:**
  - 수학: 1반 `60.0`점 / 2반 `64.0`점
  - 영어: 1반 `76.0`점 / 2반 `79.0`점
  - 프로그래밍: 1반 `84.0`점 / 2반 `88.0`점
- **핵심 결론:** 전체 평균은 1반이 높으나 세 과목 모두 2반이 높게 나타나는 과목별 데이터 구성 비율 차이에 따른 **심슨의 역설**이 확인된다. 동일 과목 기준으로는 2반의 성취도가 더 높으며, 반의 우열을 단순 전체 평균으로 단정할 수 없다.

### 3. 손계산 및 자동화 검증 (`pytest`)
- `mini.csv`(10행) 손계산 결과 7행(1반 평균 `80.0`, 2반 평균 `70.0`)이 도출되어 코드 결과와 일치함을 확인했다.
- `test_analysis.py`로 행 수 보존, 반 종류, 전체 합계 일치, `mini.csv` 평균 일치 테스트를 구성하고 `pytest -q`로 `4 passed`를 검증했다.
